# Loomcraft

A full-stack (MongoDB, Express, React, Node) storefront for handmade Indian craft: block-printed textiles, ikat weaves, brass and terracotta homeware.

## What makes it different

- **Generated block-print product art.** Product images are SVGs generated by the API (`/api/art/:slug.svg`), so the shop has its own look and never depends on third-party image hosts. Admins can also use any image URL.
- **Maker provenance.** Every piece records where it is made (for example Bagru, Rajasthan) and shows it on cards and detail pages.
- **Order tracking.** Customers get an order history with a status timeline, and can cancel an order while it is still `placed`. Cancelling returns stock atomically.
- **Safer fulfilment.** Admins can only move orders forward (placed, processing, shipped, delivered) or cancel them. Cancelled orders are excluded from revenue.
- **Self-correcting bag.** The bag re-checks price and stock with the server and caps quantities to what is available.
- **Archive, don't delete.** Removing a product archives it so past orders and favourites stay intact.

## Requirements

- Node.js 18+
- MongoDB (local or Atlas)

## Setup

```sh
npm install
cp .env.example .env     # set MONGO_URI, JWT_SECRET (32+ chars), ADMIN_EMAIL, ADMIN_PASSWORD (12+ chars)
npm run seed             # sample catalogue + admin account
npm run dev              # API on :5000, storefront on :5173
```

Sign in with your `ADMIN_EMAIL` / `ADMIN_PASSWORD` and open **Studio** in the header to manage products and orders.

`npm run seed` only inserts missing pieces. To overwrite descriptions, images and prices of the sample pieces (stock is kept), run `npm run seed -- --refresh`. Re-running the seed also resets the admin password to the value in `.env`.

## Scripts

| Script | Purpose |
| --- | --- |
| `npm run dev` | API (nodemon) and Vite together |
| `npm run build` | Production client build into `dist/` |
| `npm start` | API; with `NODE_ENV=production` it also serves `dist/` (requires `CLIENT_ORIGIN`) |
| `npm test` | API tests that run without a database |

## API

- `GET /api/config`, `GET /api/health`, `GET /api/art/:slug.svg`
- `GET /api/products` (`search`, `category`, `sort`, `limit`, `ids`), `GET /api/products/:id`
- `POST /api/auth/signup`, `POST /api/auth/login`, `GET /api/auth/me`
- `GET /api/wishlist`, `PUT /api/wishlist/:productId`
- `POST /api/orders`, `GET /api/orders`, `GET /api/orders/:id`, `POST /api/orders/:id/cancel`
- Admin: `/api/admin/products` (GET, POST, PUT, DELETE = archive), `/api/admin/orders` (GET, `PATCH /:id`)

Shipping is ₹79 under ₹1,999 and free above; change with `SHIPPING_FEE` and `FREE_SHIPPING_THRESHOLD`. Only cash on delivery is enabled; connect a payment provider before accepting online payments.
